# Laboratório de Relatórios Protheus

<br />

[English](README.md) &nbsp;|&nbsp; **Português (Brasil)**

<br />

Coleção de exemplos de relatórios em ADVPL para TOTVS Protheus — conciliação, análise de margem, documentos fiscais e relatórios de comissão utilizando TReport.

> **Aviso Legal**: Exemplos educacionais. Dados simulados, referências genéricas de tabelas e nomes fictícios. Não derivado de código de produção de nenhum cliente.

## Exemplos

### Relatório de Conciliação
Relatório de cruzamento de dados para conciliação de informações integradas entre sistemas.
  

### Relatório de Margem de Contribuição
Relatório de análise de margem com agrupamento de produtos e cálculos de lucratividade.
  

### Relatório de Documentos Fiscais
Impressão de notas fiscais com detalhamento tributário e conformidade fiscal.
  

### Relatório de Comissões
Relatório de comissão de vendas com filtro por período e agrupamento por representante.
